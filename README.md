# 👋 Hi there

Infrastructure penetration tester with a focus on **Active Directory,
Entra ID, ADCS**, and Windows internals. I ship small open-source tools
when I find myself solving the same problem twice.

> "The quieter you become, the more you are able to hear." — Rumi

# 🚀 Focus

Day-to-day I work on the full chain from unauthenticated foothold to
domain and tenant takeover, Kerberos abuse, ADCS misconfigurations,
SCCM takeovers, delegation chains, and the long tail of trust-boundary
mistakes between on-prem and cloud identity.

In parallel I research **Windows local privilege escalation**. Services running as
`NT AUTHORITY\SYSTEM` that trust input a regular user can influence:
named pipes,
`ProgramData` ACLs, update paths, DLL search order. The
kind of bug that was always there, but no one looked.

I build tools because the existing ones are either missing, abandoned,
or heavier than they need to be, or to to get a deeper understanding of how things work.
